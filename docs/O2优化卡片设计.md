# O2 优化 · 方案 B

| 项目 | 当前值 |
|---|---|
| 价格 | **$3** |
| 攻击 / 生命 | **0 / 280** |
| 购买精力 / 理智 | 9 / 16 |
| 难度 / 流派 | 提高 / 优化 |
| 技能 id | `o2_aura` |
| 短句 | 自己不跑，让队友跑得更快 |

> 被动：无法攻击，原地为周围八格友军提供攻速 ×2；同名光环不叠加，离开范围或自身阵亡后失效。

- 八格包含斜角，不包括自身，只加速友军普攻，不加速主动技能。
- 原地站定，不追敌。多个来源仍为 ×2。
- 动态检查范围及来源是否存活。普通卡在光环下普攻间隔 1 秒。
- 与 SPFA 自带攻速倍率相乘，但额外卡顿仍保持 4 秒；精确事件计时修复后，SPFA 在旧 ×1.5 光环下间隔约 0.888889 秒，当前 ×2 光环下约 0.666667 秒（无减速、不卡顿、持续在射程内）。
- 最新调整：生命由 300 降至 280，其他数值不变。

## 测试

当前 280 生命版已完成全池纯卡、两类混编和定向站位验证，机制及精确计时回归通过。当前结果见《完整检查与平衡报告.md》和《卡牌战力评分》。不要沿用旧 300 生命版的实战结论。

定位：站位型普攻辅助，适合覆盖多名稳定普攻输出；分散站位损失大，对依赖同行攻击力总和与主动技能的阵容需谨慎。
